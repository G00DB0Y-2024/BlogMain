# 强化学习进阶（二）

接上篇：本文将开始学习引入深度学习的强化学习，以应对复杂、连续的环境

表格的方法最终引出了Q-Learning，这是一种很好的强化学习范式，然而，在解决背包问题时发现，状态空间随物品数量呈指数上升，当解空间变大时，巨大的表格将难以维护

Q-Learning的本质是在估计数学期望，从而使Q-Table中每个元素都收敛到$Q_{\pi}(s,a)$, 进而控制动作的分布（指定s行，选定最大Q(s,a)对应的a）进而决策

如果能有一个模型，它可以学习，最好的结果给它状态s，能够输出每个动作的$Q_{\pi}(s,a)~~\forall a\in \mathcal{A}$, 我们就可以继续Q-Learning的决策过程，这就由 State Value Approximation方法解决。

仍然以数学期望的估计问题引入：

### 参数拟合估计数学期望

> 仍然考虑数学期望估计问题：
> $$
> f_{\theta}(X) = \mathbb{E}[X]
> $$
> 其中，要求拟合模型 $f_{\theta}(\cdot)$ 充当期望函数的功能
>
> 考虑最小二乘问题：
> $$
> L(\theta) =\mathbb{E}[(X - f_{\theta}(X))^2]
> $$
> 当 $f_{\theta}(X)$ 拟合的很好的时候，$L(\theta)=0$，因此用梯度下降使其最小：
> $$
> \nabla L = -2 \mathbb{E}[(X - f_{\theta}(X))\nabla f_{\theta}(X)]
> $$
> 利用随机梯度下降（SGD），对 $X$ 采样一个batch：$\{x_i \}_{i=1}^B$
>
> 则：
> $$
> \theta_{t+1} = \theta_t + \alpha \frac{1}{B}\sum_{i=1}^{B}(x_i - f_{\theta}(x_i))\nabla f_{\theta}(x_i)
> $$
> 当 $B=1$ 时, 可以观察，其中 $(x_i - f_{\theta}(x_i))$ 即为 TD-error
> $$
> \theta_{t+1} = \theta_t + \alpha (\underbrace{x_i - f_{\theta}(x_i)}_{TD-error})\nabla f_{\theta}(x_i)
> $$
> **值函数拟合强化学习的本质**
> $$
> L(w) = \mathbb{E}_{U}[(R_{t+1}+\gamma \max_a Q_{w}(s_{t+1},a)-Q_{w}(s_t, a_t))^2]
> $$
>
> $$
> w_{t+1} = w_t + \alpha (\underbrace{r_{t+1} + \gamma \max_{a} Q_{w}(s_{t+1},a) - Q_{w}(s_t,a_t)}_{TD-error})\nabla Q_{w}(s_t,a_t)
> $$
> 细节：
>
> - $Q_w(s,a)$ 网络输入是状态向量 $s_t$, 输出为每个动作的Action Value
>   $$
>   Q_w: \mathcal{S} \rarr \R^{|\mathcal{A}|}
>   $$
>
> - 神经网络依据 loss 工作，设定好loss，其期望结果就是loss为0时的结果



**算法：利用参数拟合估计数学期望**

- X 采用参数为 5 的泊松分布
- 一次生成X观测的一个批量，即一个数组，理解DQN的关键就在于这个batch
- 神经网络不需要太多层，一层隐藏层即可

```python
import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

def X(batch):
    return [np.random.poisson(5) for _ in range(batch)]  #随机变量服从均值为5的泊松分布

# 定义神经网络
class Qnet(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(Qnet, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        return self.fc2(x)

# 初始化
batch = 5
dqn = Qnet(1, 5, 1)
optimizer = torch.optim.SGD(dqn.parameters(), lr=0.01)
criterion = torch.nn.MSELoss( reduction='mean')

mean_td = [] #时序差分记录
mean_mc = [] #蒙特卡洛记录
mean_estimate = []

x_td = 10  #时序差分
x_mc = 0  #蒙特卡洛
td_a = 0.01  #TD学习率

for i in range(1000):
    x_t = X(batch)  # 获取随机变量的观测值

    for x in x_t:
        x_td += td_a*(x - x_td)
    x_mc += sum(x_t)

    xt_tensor = torch.tensor(x_t, dtype=torch.float32).reshape(-1,1)

    # 估计均值
    V_t = dqn(xt_tensor)

    # 计算当前损失
    loss = criterion(V_t, xt_tensor)  # 这里直接计算当前的损失

    optimizer.zero_grad()
    loss.backward()  # 反向传播
    optimizer.step()  # 更新参数
        
    # 记录结果
    mean_estimate.append(V_t.mean().item())
    mean_td.append(x_td)
    mean_mc.append(x_mc/((i+1)*batch))

# 绘制结果
plt.plot(mean_td, color='#3fc345', label=f"TD-Method alpha={td_a}")
plt.plot(mean_mc, color='#f9816c', label="Monte Carlo")
plt.plot(mean_estimate, color='#5f7af5', label="Model Estimate")
plt.legend()
plt.show()
```

**结果分析：**

- 对比蒙特卡洛、TD算法，模型在一开始不能很好地学习到规律
- 在收敛后，模型可以平稳地估计X的期望，总体来看，和TD的规律差不多，而蒙特卡洛总是非常平稳
- 如果batch过小，模型将不能学习到规律，而TD方法任意batch都可以学习



### DQN

> 问题：最速降线优化
>
> 生成从 $(0,0)$ 滑落到 $(1,-1)$ 的曲线，使物体仅在重力作用下滑落。曲线由二阶贝塞尔曲线生成，仅操作控制点$P(x,y) ~~ x \in [-5,5],y \in  [-5,5]$ ，求时间最短曲线的控制点位置。
>
> <img src="./assets/image-20250303104933366.png" alt="image-20250303104933366" style="zoom:50%;" />



DQN的引入即为了将Q-table参数化，以应对：1. 超高维度的状态空间；2.连续的状态空间

在引入策略梯度法之前，我们能够处理的**动作**都还只是**离散的**

在最速降线问题中，可以看到状态空间如下：

| 维度 |    意义     | 最小值 | 最大值 |
| :--: | :---------: | :----: | :----: |
|  0   | 控制点x坐标 |   -5   |   5    |
|  1   | 控制点y坐标 |   -5   |   5    |

**动作**目前只能**离散**，动作空间如下所示：

| 维度 |         动作         |
| :--: | :------------------: |
|  0   | 控制点x  $-\Delta s$ |
|  1   | 控制点x $+\Delta s$  |
|  2   | 控制点y $-\Delta s$  |
|  3   | 控制点y $+\Delta s$  |

其中 $\Delta s$ 即为对动作的离散，取得越细，则最终结果越准确



**目标网络和经验回放**

在数学期望估计的问题中，发现一些问题：

1. 由于 TD 误差目标本身就包含神经网络的输出，因此在更新网络参数的同时目标也在不断地改变，这非常容易造成神经网络训练的不稳定性
2. 观测 $X$ 后生成很多数据，然而每个数据只用于训练了一次，造成浪费

为解决问题 1，提出：**目标网络**概念

- 设置一个目标网络 $Q_{w^-}$，其参数不变并生成目标 $r_{t+1} + \gamma \max_{a} Q_{w^-}(s_{t+1},a)$
- 价值网络正常计算损失并更新参数
- 每迭代一定次数后，将价值网络的参数赋值给目标网络

为解决问题 2，提出：**经验回放**概念

- 维护一个**回放缓冲区**，将每次的SARS观测数据存储到回放缓冲区

- 每次从缓冲区取一个批量进行训练

  作用：

  1. 使样本满足独立假设： $\mathbb{E}_{U}[(R_{t+1}+\gamma \max_a Q_{w}(s_{t+1},a)-Q_{w}(s_t, a_t))^2]$ 中数据越接近均匀分布，其梯度估计的越准确
  2. 提高样本效率，每一个样本可以被使用多次。



环境类实现：

- 环境类需要实现的接口
  - reset：用于给定一个合法状态，初始化解
  - evaluation(state) -> value：评估一个状态
  - step(state, action) -> next_state, reawrd：根据动作转移状态，给出该转移的奖励
- 奖励设置
  - 奖励只需要能迫使agent向最优解走即可
  - 设置：如果转移后状态相比于转移前花费更少时间，则强化奖励
    - 如果超出界限，则惩罚
- 转移设置
  - ds控制每次转移在坐标上能跳跃的大小，离散化了空间
  - ds越小，越接近最优解，然而越难搜索

```python
class CurveEnv:
    def reset(self):
        return [random.uniform(0,1), random.uniform(-1,0)]  #初始物理状态
    
    def evaluation(self, state):
        # 0,0   1,-1
        x_s, y_s = state
        #评估函数，根据当前状态评估奖励
        x = lambda t: (1-t)*t*x_s + t**2*1
        dx = lambda t: (1-t)*x_s - t*x_s + 2*t

        y = lambda t: (1-t)*t*y_s + t**2*(-1)
        dy = lambda t: (1-t)*y_s - t*y_s + -2*t

        #积分计算总时间
        dt = 0.01
        t=0
        g = 9.8
        T = 0
        for t in np.arange(dt,1,dt):
            dxt = dx(t)*dt
            dyt = dy(t)*dt
            vt = np.sqrt(abs(2*y(t)*g))
            ds = np.sqrt(dxt**2 + dyt**2)
            T += ds/vt
        
        return T

    def step(self, state, action):
        '''
        动作编码：0 1 2 3 4...
        0 表示 第1个二进制位 = 0
        1 表示 第1个二进制位 = 1
        以此类推

        return next_state, reward
        '''
        #根据动作转移状态
        dx=0
        dy=0
        ds=0.01
        if action == 0:
            dx=-ds
        elif action == 1:
            dx=ds
        elif action == 2:
            dy=-ds
        elif action == 3:
            dy=ds
        s_next = [state[0]+dx, state[1]+dy]
        #评估状态
        T_ori = self.evaluation(state)
        T_new = self.evaluation(s_next)
        
        if state[0]>0 and state[1]<0:
            r = 10*(T_ori-T_new) + (10 if T_ori>T_new else -10)
        else:
            r = -100
        return s_next, r, T_new
```



DQN算法实现

- 只用一层的Qnet即可
- 需要实现两个接口：
  - take_action(state): 根据当前状态做出动作，根据价值Qnet的输出选出最大的一个（决策模型）
    - 仍然需要贪婪策略，因为输出Policy仍然是离散的
  - update(next_state): 接收环境反馈的next_state，进行记忆，并对价值网络进行更新，并间隔一定轮数更新目标网络 

- DDQN：缓解DQN对于价值估计过高的情况
  - 区别在于：利用目标网络 $Q_{w^-}$ 生成目标 $r+\gamma \max_{a} Q_{w^-}(s,a)$ 时，其中 $a$ 由价值网络给出：$a = \arg \max_{a} Q_{w}(s,a)$

```python
class DQN:
    ''' DQN算法 '''
    def __init__(self, state_dim, hidden_dim, action_dim, learning_rate, gamma, epsilon, target_update, device, dqn_type='DQN'):
        self.action_dim = action_dim
        self.value_q_net = Qnet(state_dim, hidden_dim,
                          self.action_dim).to(device)  # Q网络
        # 目标网络
        self.target_q_net = Qnet(state_dim, hidden_dim,
                                 self.action_dim).to(device)
        # 使用Adam优化器
        self.optimizer = torch.optim.Adam(self.value_q_net.parameters(),
                                          lr=learning_rate)
        self.gamma = gamma  # 折扣因子
        self.epsilon = epsilon  # epsilon-贪婪策略
        self.target_update = target_update  # 目标网络更新频率
        self.count = 0  # 计数器,记录更新次数
        self.device = device
        self.dqn_type = dqn_type

    def take_action(self, state):  # epsilon-贪婪策略采取动作
        if np.random.random() < self.epsilon:
            action = np.random.randint(self.action_dim)
        else:
            state = torch.tensor(state, dtype=torch.float).to(self.device)
            action = self.value_q_net(state).argmax().item()
        return action

    def update(self, transition_dict):
        states = torch.tensor(transition_dict['states'],
                              dtype=torch.float).to(self.device)
        actions = torch.tensor(transition_dict['actions']).view(-1, 1).to(
            self.device)
        rewards = torch.tensor(transition_dict['rewards'],
                               dtype=torch.float).view(-1, 1).to(self.device)
        next_states = torch.tensor(transition_dict['next_states'],
                                   dtype=torch.float).to(self.device)

        q_values = self.value_q_net(states).gather(1, actions)  # Q值

        # 下个状态的最大Q值
        if self.dqn_type == 'DDQN': # DQN与Double DQN的区别
            max_action = self.q_net(next_states).max(1)[1].view(-1, 1)
            max_next_q_values = self.target_q_net(next_states).gather(1, max_action)
        else: # DQN的情况
            max_next_q_values = self.target_q_net(next_states).max(1)[0].view(-1, 1)

        q_targets = rewards + self.gamma * max_next_q_values

        dqn_loss = torch.mean(F.mse_loss(q_values, q_targets))  # 均方误差损失函数
        self.optimizer.zero_grad()  # PyTorch中默认梯度会累积,这里需要显式将梯度置为0
        dqn_loss.backward()  # 反向传播更新参数
        self.optimizer.step()

        if self.count % self.target_update == 0:
            self.target_q_net.load_state_dict(
                self.value_q_net.state_dict())  # 更新目标网络
        self.count += 1
```



经验回放实现

- 经验回放在训练阶段使用，因为需要环境的反馈，其搜集SARS数据 $(s_t, a_t, r_{t+1}, s_{t+1})$
- 和环境一样，经验池也应当在原生的变量环境下工作，由agent自身进行张量转换

```python
class ReplayBuffer:
    ''' 经验回放池 '''
    def __init__(self, capacity):
        self.buffer = collections.deque(maxlen=capacity)  # 队列,先进先出

    def add(self, state, action, reward, next_state):  # 将sars数据加入buffer
        self.buffer.append((state, action, reward, next_state))

    def sample(self, batch_size):  # 从buffer中采样数据,数量为batch_size
        transitions = random.sample(self.buffer, batch_size)
        state, action, reward, next_state = zip(*transitions)
        return np.array(state), action, reward, np.array(next_state)

    def size(self):  # 目前buffer中数据的数量
        return len(self.buffer)
```



训练过程

- 训练过程仍然为两个循环：Iteration循环和sampling循环，共计Epoch：Iteration × sampling
- 此次实现没有仅仅让agent自己记着S和A，而是进行输出，因为经验回放池需要这些数据
  - 当然也可以只让agent记住，将经验池引用丢给agent

```python
lr = 2e-3
hidden_dim = 128
gamma = 0.9
epsilon = 0.1
target_update = 10
buffer_size = 10000
minimal_size = 500
batch_size = 64
device = torch.device("cuda") if torch.cuda.is_available() else torch.device("cpu")

env = CurveEnv()
random.seed(0)
np.random.seed(0)
torch.manual_seed(0)
replay_buffer = ReplayBuffer(buffer_size)
state_dim = 2
action_dim = 4
agent = DQN(state_dim, hidden_dim, action_dim, lr, gamma, epsilon, target_update, device)

return_list = []
iters = 500

best_t = np.inf
best_p = []

Tarr = []
Parr = []

with tqdm(total=int(iters)) as pbar:
    for i_episode in range(iters):
        episode_return = 0
        state = env.reset()
        sampling_len = 10
        for _ in range(sampling_len):
            action = agent.take_action(state)
            next_state, reward, T = env.step(state, action)
            replay_buffer.add(state, action, reward, next_state)
            state = next_state
            episode_return += reward

            if T <= best_t:
                best_t = T
                best_p = next_state

            #记录
            Tarr.append(best_t)
            

            # 当buffer数据的数量超过一定值后,才进行Q网络训练
            if replay_buffer.size() > minimal_size:
                b_s, b_a, b_r, b_ns = replay_buffer.sample(batch_size)
                transition_dict = {
                    'states': b_s,
                    'actions': b_a,
                    'next_states': b_ns,
                    'rewards': b_r,
                }
                agent.update(transition_dict)

        return_list.append(episode_return)
        Parr.append([*next_state, T])

        if (i_episode + 1) % 10 == 0:
            pbar.set_postfix({
                'episode':
                '%d' % (i_episode + 1),
                'best P1':
                f'{best_p} -  {best_t:.04f}s',
                'return':
                '%.3f' % np.mean(return_list[-10:])
            })
        pbar.update(1)
```
