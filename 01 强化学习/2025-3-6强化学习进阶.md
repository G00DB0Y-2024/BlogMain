# 强化学习进阶（五）

先把价值目标表格放在这里

|                             公式                             |           含义           |
| :----------------------------------------------------------: | :----------------------: |
|                 $\sum_{n=0}^{T}\gamma^nr_n$                  |        轨迹总回报        |
|               $\sum_{n=t}^{T}\gamma^{n-t} r_n$               |  动作 $a_t$ 之后的回报   |
|          $\sum_{n=t}^{T}\gamma^{n-t} r_n - b(s_t)$           |      基线改进版回报      |
|                  $Q^{\pi_\theta}(s_t, a_t)$                  |       动作价值函数       |
| $A^{\pi_\theta}(s_t, a_t)=\sum_{n=t}^{T}\gamma^{n-t} r_n - V^{\pi_\theta}(s_t)$ | 动作优势函数（**A2C***） |
| $r_t + \gamma V^{\pi_\theta}(s_{t+1}) - V^{\pi_\theta}(s_t)$ | 时序查分残差（优势近似） |

本篇将针对策略梯度法的一些不足，介绍改进算法



### 信任域策略优化

##### 单调递增策略

在 $\pi_\theta$ 下，希望找到 $\theta'$ 使得 $J(\theta') \ge J(\theta)$，考虑以下关系
$$
J(\theta) =  -\mathbb{E}[\sum_{t=0}^{\infty}\gamma^t(\gamma V^{\pi\theta}(S_{t+1})-V^{\pi\theta}(S_{t}))]
$$
得带新旧策略目标函数的差距：
$$
J(\theta')-J(\theta) = \mathbb{E}[\sum_{t=0}^{\infty}\gamma^t(r(S_t, A_t)+\gamma V^{\pi\theta}(S_{t+1})-V^{\pi\theta}(S_{t}))]
$$
其中：$A(s_t, a_t)=r(s_t, a_t)+\gamma V^{\pi\theta}(s_{t+1})-V^{\pi\theta}(s_{t})$ 称为“**优势函数**”

结论：所以只要我们能找到一个新策略，使得 $\mathbb{E}[A^{\pi\theta}(S,A)] \ge 0$，就能保证策略性能单调递增



##### 信任域策略优化定理（TRPO）

$$
\begin{aligned}
\max _{\theta^{\prime}} & L_{\theta}\left(\theta^{\prime}\right) \\
\text { s.t. } & \mathbb{E}_{s \sim \nu^{\pi \theta_{k}}}\left[D_{K L}\left(\pi_{\theta_{k}}(\cdot \mid s), \pi_{\theta^{\prime}}(\cdot \mid s)\right)\right] \leq \delta
\end{aligned}
$$
其中：
$$
L_{\theta}\left(\theta^{\prime}\right)=J(\theta)+\mathbb{E}_{s \sim \nu^{\pi_{\theta}}} \mathbb{E}_{a \sim \pi_{\theta}(\cdot \mid s)}\left[\frac{\pi_{\theta^{\prime}}(a \mid s)}{\pi_{\theta}(a \mid s)} A^{\pi_{\theta}}(s, a)\right]
$$
约束条件定义了一个KL散度球，为了保证新旧策略足够接近，上述指标才成立



##### 近端策略优化（PPO）

上述的TRPO思想求解非常复杂，为了简化，提出PPO算法
$$
\arg \max_{\theta} ~\mathbb{E}\left[\min \left\{ \frac{\pi_{\theta}(a \mid s)}{\pi_{\theta_{k}}(a \mid s)} , \text{clip}\left(\frac{\pi_{\theta}(a \mid s)}{\pi_{\theta_{k}}(a \mid s)}, 1-\epsilon, 1+\epsilon\right) \right \}  \cdot A^{\pi_{\theta_{k}}}(s, a)\right]
$$
即将重要性采样 $\dfrac{\pi_{\theta}(a \mid s)}{\pi_{\theta_{k}}(a \mid s)}$ 截断在 $(1-\epsilon, 1+\epsilon)$的范围内，取其下界后和优势函数相乘。这样做是保证两个分布的间距不会太大，如果 $A^{\theta} \ge 0$，会增大重要性采样，但是不会让其超过 $1+\epsilon$，反之亦然。

PPO的截断思想的惩罚形式为TRPO的拉格朗日乘数法：
$$
\arg \max_{\theta} ~~\mathbb{E}\left[\frac{\pi_{\theta}(a \mid s)}{\pi_{\theta_{k}}(a \mid s)} A^{\pi_{\theta_{k}}}(s, a)-\beta D_{K L}\left[\pi_{\theta_{k}}(\cdot \mid s), \pi_{\theta}(\cdot \mid s)\right]\right]
$$


##### 处理连续动作空间

可以看到，PPO输出的仍然是一个概率分布，这和DQN等离散优化是一样的；由于PPO的优化指标中含有分布函数，这使其可以处理连续域

我们只需要让策略网络生成一个分布，随后用该分布采样动作，并带入指标中计算。常见让策略网络输出连续动作**高斯分布**（Gaussian distribution）的均值和标准差，后续的连续动作则在该高斯分布中采样得到。



### 问题引入

> 考虑最优控制问题：汽车从 $x=0$ 启动，到 $x_1=100 \text{m}$ 停下，司机可以输入力：
> $$
> F \in [-10,10] ~(N)
> $$
> 负数表示刹车，正数表示加速。只有在加速时候，发动机才做功。
>
> 汽车运动过程中，受空气阻力：
> $$
> f(t)=-kv(t) ~(N)
> $$
> 比例常数 $k=0.5$，汽车质量 $m=5 \text{kg}$，要求汽车停在终点，并使能耗：
> $$
> E = \int_{0}^{x_1} \max \{0, F\} ~\text{d}x
> $$
> 达到最小。求最优控制律 $F(t)$

该问题最难的部分仍然是终端约束，汽车需要停在终点，即其终端速度为0



### PPO-Discrete

在离散域求解该问题，即将动作空间离散，分解为
$$
F = [-10,-8,-6,-4,-2,0,2,4,6,8,10] ~\text{N}
$$
汽车控制级，其中负数表示刹车级，正数表示加速级；策略网络输出维度为11的多项分布

状态空间： 3个维度 
$$
=\mathcal{S}:= \{x, v, x_r\} = \{ x, v, x_\text{end}-x \}_t
$$
汽车环境的实现仍然是首要重要的，因为强化学习对于环境敏感的性质，如果环境的奖励函数分布不好，不仅无法处理约束，agent可能无法完成任务，甚至无法训练

奖励函数设计如下：
$$
r_{t+1} = r_{x} + r_E + r_{\text{end}} + r_{\text{failure}}
$$
其中，各部分设计如下：

- $r_x = -0.001 \cdot |x_{t+1} - x_\text{end}|$：位移引导项，引导agent能够不断靠近目标
- $r_E = -0.001 \cdot \int_{0}^{x_{t+1}}\max\{0,F\}~\text{d}x$：能耗引导项，引导agent不断减少能耗。和位移引导一样，其系数不宜过大，否则将淹没终端奖励
- $r_\text{end} = \mathbb{I}\{ x_{t+1} \ge x_\text{end} \}(10000 - 1000 \cdot |v_{t+1}|)$：终端稀疏奖励，对于成功完成任务且满足终端约束的agent给予大额奖励，以促使其他agent走向该轨迹，该奖励应当较大，且完成任务奖励不应淹没终端约束罚项，而整体奖励不应被引导项淹没
- $r_\text{failure} = \left\{ \begin{align} &-100,~~ x_{t+1} \le x_t \\ &-1000,~~ (t+1)\text{d}t \ge T_\text{max} \end{align} \right.$： 失败罚项，对于异常运动、超出限制时间的agent给予惩罚，该惩罚不宜过大，否则将阻滞训练，异常运动的惩罚**不应当返回`done = True`**，否则将使初期多数agent在异常运动的位置停止探索；超出限制时间应当返回`done=True`，否则将使训练陷入死循环

```py
class CarEnv:
    def __init__(self):
        self.dt = 0.1  # 时间步长
        self.x_end = 100  # 终点位置
        self.m_car = 5  # 汽车质量
        self.k_air = 0.5
        self.max_T = 30  # 最大时间步数
        self.state = []
        self.force_list = [-10,-8,-6,-4,-2,0,2,4,6,8,10]

    def reset(self):
        self.sumT = 0  # 总时间
        self.sumE = 0
        self.state = [0,0,self.x_end]
        return self.state  # 初始状态 (位移，速度)

    def step(self, action):
        '''
        state = [位移，速度]
        action = 力
        
        return 下一帧状态，当前帧奖励，是否终止
        '''
        x = self.state[0]
        v = self.state[1]

        f_car = self.force_list[action] # action = 0~10

        at = (f_car - self.k_air*v)/self.m_car
        v1 = v + at * self.dt
        x1 = x + v1 * self.dt
        dE = max(0,f_car)*(x1 - x)

        self.sumE += dE
        self.sumT += self.dt
        

        r = 0
        
        #刹车条件
        if x1 <= x:
            r = -100
            done = False

        elif self.sumT > self.max_T:
            r -= 1000
            done = True

        else:
            #位移引导项
            r += -0.001*abs(x1 - self.x_end) 

            #能量引导项
            r += -0.001*self.sumE
            
            # 刹车条件
            if x >= self.x_end:
                r += 10000 - 1000*abs(v1)
                done = True
            else:
                done = False

        self.state = [x1, v1, self.x_end - x1]
        res = {
            'T': self.sumT,
            "x": x1,
            "v": v1,
            "F": f_car,
            "E": self.sumE,
        }

        return self.state, r, done, res
```

class PolicyNet(torch.nn.Module):
    def __init__(self, state_dim, hidden_dim, action_dim):
        super(PolicyNet, self).__init__()
        self.fc1 = torch.nn.Linear(state_dim, hidden_dim)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        return F.softmax(self.fc2(x), dim=1)

        self.fc2 = torch.nn.Linear(hidden_dim, 1)

PPO算法设计

```py
class PPO:
    ''' PPO算法,采用截断方式 '''
    def __init__(self, state_dim, hidden_dim, action_dim, actor_lr, critic_lr,
                 lmbda, epochs, clip_eps, gamma, device):
        self.actor = PolicyNet(state_dim, hidden_dim, action_dim).to(device)
        self.critic = ValueNet(state_dim, hidden_dim).to(device)
        self.actor_optimizer = torch.optim.Adam(self.actor.parameters(),
                                                lr=actor_lr)
        self.critic_optimizer = torch.optim.Adam(self.critic.parameters(),
                                                 lr=critic_lr)
        self.gamma = gamma
        self.lmbda = lmbda
        self.epochs = epochs  # 一条序列的数据用来训练轮数
        self.clip_eps = clip_eps  # PPO中截断范围的参数
        self.device = device

    def take_action(self, state):
        state = torch.tensor([state], dtype=torch.float).to(self.device)
        probs = self.actor(state)
        action_dist = torch.distributions.Categorical(probs)
        action = action_dist.sample()
        return action.item()

    def update(self, transition_dict):
        states = torch.tensor(transition_dict['states'], dtype=torch.float).to(self.device)
        actions = torch.tensor(transition_dict['actions']).view(-1, 1).to(self.device)
        rewards = torch.tensor(transition_dict['rewards'], dtype=torch.float).view(-1, 1).to(self.device)
        next_states = torch.tensor(transition_dict['next_states'], dtype=torch.float).to(self.device)
        dones = torch.tensor(transition_dict['dones'], dtype=torch.float).view(-1, 1).to(self.device)
        
        td_target = rewards + self.gamma * self.critic(next_states) * (1 - dones)
        td_delta = td_target - self.critic(states)

        advantage = rl_utils.compute_advantage(self.gamma, self.lmbda, td_delta.cpu()).to(self.device)
        old_log_probs = torch.log(self.actor(states).gather(1,actions)).detach()

        for _ in range(self.epochs):
            log_probs = torch.log(self.actor(states).gather(1, actions))
            ratio = torch.exp(log_probs - old_log_probs)
            surr1 = ratio * advantage
            surr2 = torch.clamp(ratio, 1 - self.clip_eps, 1 + self.clip_eps) * advantage  # 截断
            actor_loss = torch.mean(-torch.min(surr1, surr2))  # PPO损失函数
            critic_loss = torch.mean(F.mse_loss(self.critic(states), td_target.detach()))
            self.actor_optimizer.zero_grad()
            self.critic_optimizer.zero_grad()
            actor_loss.backward()
            critic_loss.backward()
            self.actor_optimizer.step()
            self.critic_optimizer.step()
```

```py
def train_on_policy_agent(env, agent, num_episodes):
    return_list = []
    for i in range(10):
        with tqdm(total=int(num_episodes/10), desc='Iteration %d' % i) as pbar:
            for i_episode in range(int(num_episodes/10)):
                episode_return = 0
                transition_dict = {'states': [], 'actions': [], 'next_states': [], 'rewards': [], 'dones': []}
                state = env.reset()
                done = False
                while not done:
                    action = agent.take_action(state)
                    next_state, reward, done, _ = env.step(action)
                    transition_dict['states'].append(state)
                    transition_dict['actions'].append(action)
                    transition_dict['next_states'].append(next_state)
                    transition_dict['rewards'].append(reward)
                    transition_dict['dones'].append(done)
                    state = next_state
                    episode_return += reward
                return_list.append(episode_return)
                agent.update(transition_dict)
                if (i_episode+1) % 10 == 0:
                    pbar.set_postfix({'episode': '%d' % (num_episodes/10 * i + i_episode+1), 'return': '%.3f' % np.mean(return_list[-10:])})
                pbar.update(1)
    return return_list
```

### PPO-Continuous

在连续域解决问题，需要修改策略网络的输出：

- 输出正态分布的均值的方差

```py
class PolicyNetContinuous(torch.nn.Module):
    def __init__(self, state_dim, hidden_dim, action_dim):
        super(PolicyNetContinuous, self).__init__()
        self.fc1 = torch.nn.Linear(state_dim, hidden_dim)
        self.fc_mu = torch.nn.Linear(hidden_dim, action_dim)
        self.fc_std = torch.nn.Linear(hidden_dim, action_dim)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        mu = 10 * torch.tanh(self.fc_mu(x))
        std = F.softplus(self.fc_std(x))
        return mu, std
```

对PPO迭代算法做一定的修改：

- `f = torch.distributions.Normal(mu.detach(), std.detach())` 创建一个分布
  - `f.sample()` 可以进行一个采样，用于动作输出
  - `f.log_prob(x)` 是计算给定值 `x` 在该正态分布下的对数概率密度函数值。返回的是概率密度函数的自然对数

```python
class PPOContinuous:
    ''' 处理连续动作的PPO算法 '''
    def __init__(self, state_dim, hidden_dim, action_dim, actor_lr, critic_lr,
                 lmbda, epochs, eps, gamma, device):
        self.actor = PolicyNetContinuous(state_dim, hidden_dim,
                                         action_dim).to(device)
        self.critic = ValueNet(state_dim, hidden_dim).to(device)
        self.actor_optimizer = torch.optim.Adam(self.actor.parameters(),
                                                lr=actor_lr)
        self.critic_optimizer = torch.optim.Adam(self.critic.parameters(),
                                                 lr=critic_lr)
        self.gamma = gamma
        self.lmbda = lmbda
        self.epochs = epochs
        self.eps = eps
        self.device = device

    def take_action(self, state):
        state = torch.tensor([state], dtype=torch.float).to(self.device)
        mu, sigma = self.actor(state)
        action_dist = torch.distributions.Normal(mu, sigma)
        action = action_dist.sample()
        return action.item()

    def update(self, transition_dict):
        states = torch.tensor(transition_dict['states'],
                              dtype=torch.float).to(self.device)
        actions = torch.tensor(transition_dict['actions'],
                               dtype=torch.float).view(-1, 1).to(self.device)
        rewards = torch.tensor(transition_dict['rewards'],
                               dtype=torch.float).view(-1, 1).to(self.device)
        next_states = torch.tensor(transition_dict['next_states'],
                                   dtype=torch.float).to(self.device)
        dones = torch.tensor(transition_dict['dones'],
                             dtype=torch.float).view(-1, 1).to(self.device)
        rewards = (rewards + 8.0) / 8.0  # 和TRPO一样,对奖励进行修改,方便训练
        td_target = rewards + self.gamma * self.critic(next_states) * (1 - dones)
        td_delta = td_target - self.critic(states)
        advantage = rl_utils.compute_advantage(self.gamma, self.lmbda, td_delta.cpu()).to(self.device)
        mu, std = self.actor(states)
        action_dists = torch.distributions.Normal(mu.detach(), std.detach())
        # 动作是正态分布
        old_log_probs = action_dists.log_prob(actions)

        for _ in range(self.epochs):
            mu, std = self.actor(states)
            action_dists = torch.distributions.Normal(mu, std)
            log_probs = action_dists.log_prob(actions)
            ratio = torch.exp(log_probs - old_log_probs)
            surr1 = ratio * advantage
            surr2 = torch.clamp(ratio, 1 - self.eps, 1 + self.eps) * advantage
            actor_loss = torch.mean(-torch.min(surr1, surr2))
            critic_loss = torch.mean(
                F.mse_loss(self.critic(states), td_target.detach()))
            self.actor_optimizer.zero_grad()
            self.critic_optimizer.zero_grad()
            actor_loss.backward()
            critic_loss.backward()
            self.actor_optimizer.step()
            self.critic_optimizer.step()
```

- 策略倾向于约前10秒全力加速，随后刹车并借助空气阻力完成在终点的停止过程，这和能耗最小的逻辑一致



##### 结论

PPO学习相当快：在训练过程中**，如果agent有一次完成了任务（return>0），后续很快整体都会开始向完成任务收敛，这才是正常的训练过程**

- 连续和离散的情况类似，由于连续域是对分布采样，因此有一些震荡，然而即便如此，在前八秒的决策几乎是恒定的，和离散的情况一致，体现了PPO强大的学习能力
- 曲线上看，agent几乎完成了任务，在终端的速度很小，且能耗在某个阶段不再上升

PPO迭代速度很快，如果遇到迭代速度很慢，或是卡住不动，以下是遇见过的错误设置
- 环境方面：
  - 没有超时结束，初期大量agent陷入死循环
  - 环境罚项、引导项淹没了终端奖励，终端奖励不够大，约束不够明显，agent不能完成任务，负优化或陷入局部最优
  - 环境奖励没有引导agent完成任务， 负优化，卡死
  - 环境没有正确处理agent的异常动作，卡死
  - 环境没有按照正常规律转移状态，如对于异常动作，强行将速度归零，将使agent学习到错误的规则
  
- 训练方面
  - 学习率过大或者过小，体现为returns不收敛、震荡、收敛到大负值、负优化
  
  - 预见性 $\gamma$ 调节不恰当，一般是 0.98，越大将越会重视积累效应，即强化引导项，如果其设置过小，agent将不能完成任务
  
  - 网络过大，过深，体现为梯度消失，体现为returns不能迅速正向优化
  
  - 单轮过拟合：设置一个Iteration迭代次数过多，体现为returns先正向优化，然后突然开始急剧下降，一般在下一个轮次会得到改善，但如果在下一个轮次仍然负优化，考虑缩短训练轮次
  
  - 探索性不足：PPO输出是概率分布，因此本身就是一个随机策略，然而对于确定性策略，在初期必须增加噪声使其至少完成过任务，否则将陷入局部无法跳出
  
    

需要注意的是，TRPO 和 PPO 都属于在线策略学习算法，即使优化目标中包含重要性采样的过程，但其只是用到了上一轮策略的数据，而不是过去所有策略的数据。

PPO 是 TRPO 的第一作者 John Schulman 从加州大学伯克利分校博士毕业后在 OpenAI 公司研究出来的。通过对 TRPO 计算方式的改进，PPO 成为了最受关注的深度强化学习算法之一，并且其论文的引用量也超越了 TRPO。
