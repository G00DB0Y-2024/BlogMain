在上篇“强化学习的一些范式”中提到强化学习的运作规律，本文将总结一些常用的强化学习算法，并给出实验

### 强化学习能解决的问题

**序贯决策（sequential decision making）任务**

- 又称为：不完全可观察马尔可夫决策过程 POMDP 
- 可以是离散的，也可以是连续的
- 可以被建模为：决策引起的状态转移，并达到或优化一个具体指标

##### 和遗传算法GA的区别

遗传算法是本人最早接触的优化算法，在学习强化学习之后，发现遗传算法和强化学习有诸多异同

遗传算法是一种特殊的强化学习

- **状态：**由多个基因编码组成的种群构成集合，这是GA单次迭代能覆盖的最大状态空间

- **状态空间：**GA的基因编码所能覆盖的解空间

- **动作：**在变异算子和自然选择算子作用后，最优解发生转移，同时种群覆盖的解空间发生转移

- **动作空间：**GA的动作建立在基因编码上，因此并不是在实际环境中做出交互，而是通过修改基因完成状态的切换。其动作空间较为复杂，由变异和选择算子共同形成Policy

- **奖励**：瞬时奖励发生于动作执行后，一般认为变异和选择之后，与上代最优适应度之差为瞬时奖励，而稳态奖励即为当前代最优适应度。因此，GA缺少积累过程，我们无法判断在无穷代之后稳态奖励是否收敛。

和强化学习相比，编码都是必要的：

- 遗传算法必须声明基因的编码，最新研究有提出“可变长基因”的遗传算法，但是本质来讲，基因编码的就是一个符合基因操作的空间，并对解空间形成满射
- 强化学习的状态编码一般为实际量，如“速度、角度”，也可以是由神经网络感知后的编码，如一个图像或者一段语音经过编码器得到的特征向量，这也是RL比GA更加强大的地方

遗传算法和强化学习都适用于黑盒系统：

- 遗传算法通过选择算子和变异算子以“隐含梯度”的方式逼迫种群向最优解靠近，只需要得到系统的输入输出即可
- 强化学习通过感知环境并做出动作，以“贝尔曼最优方程”向最优解靠近，奖励往往和系统输入输出相关，剩下的都由贝尔曼方程控制



### 强化学习的本质

> 求数学期望的算法基础：
>
> 蒙特卡洛方法：算数平均是数学期望的无偏估计
> $$
> \lim_{N \rarr \infty} \frac{1}{N}\sum_{n=1}^Nx_i = \mathbb{E}[X]
> $$
> 时序差分方法：以随机近似理论（RM算法）逼近随机解
> $$
> \text{sol:}~~ x = \mathbb{E}[X] \\
> \Leftrightarrow \\
> x_{t+1} = x_t + \alpha[ \underbrace{X_t - x_t}_{TD-error} ]
> $$
> **强化学习的本质：贝尔曼最优方程**
> $$
> V_{\pi}(s) = \max_{\pi}~\mathbb{E}[R_{t+1} +\gamma V_{\pi}(s_{t+1})|S_{t}=s]  ~~~~  \forall s\in \mathcal{S}
> $$
> 其是一个数学期望估计问题；同时，其要求所有State Value达到最优，因此，强化学习也是一个多目标优化问题(MOP)



算法：蒙特卡洛法和时序差分法的对比

```python
def X(): #观测函数.
```

### Genetic Algorithm

我们以背包问题为例

> 有一个容量为 $W=5$ 的背包，一些些物品分别有两个属性：体积 w  和价值 v ，且每种物品都只有一个。现要求将这些物品在不超过容量的前提下装入背包中，并使得此背包的价值最大。
>
> | 体积 | 价值 |
> | :--: | :--: |
> |  1   |  2   |
> |  2   |  4   |
> |  3   |  4   |
> |  4   |  5   |
>
> 最优解：选取物品 2,3，得到最大价值 8

准确来说，遗传算法并不是一种强化学习，但是我仍然希望将该算法放置在最前面，以便和后续的强化学习算法比较异同

遗传算法利用基因操作完成解的转移，并不断寻找种群的最优势个体



**遗传算法：**

- 评估和选择：
  - 评估需要先给个体赋予适应度，随后按照选择算子将种群数量恢复到生态容量
- 变异：
  - 变异需要先交叉，扩充种群，随后突变；每个个体都会突变，每个基因点位按照概率突变
  - 如果有精英保护策略，则最优个体不突变

GA类和Sys类的简单实现：

```python
class Sys:
    def __init__(self, bag_weights, bag_values, max_w):
        self.bag_weights = bag_weights
        self.bag_values = bag_values
        self.max_w = max_w

    def evaluation(self, state):
        #评估函数，根据当前状态评估奖励
        sum_w = 0
        sum_v = 0
        for i, s in enumerate(state):
            if s==1:
                sum_v += self.bag_values[i]
                sum_w += self.bag_weights[i]

        if sum_w > self.max_w:
            return -10
        return sum_v


class GA:
    def __init__(self, k, cho, pc, pm, glen, system):
        '''
        K: 生态容量（每次自然选自后，都会将种群数量重置到该大小）
        cho:  锦标赛选择规模
        pc: 交叉概率
        pm: 单点位基因突变概率
        glen: 二进制基因长度
        '''
        self.k = k
        self.cho = cho
        self.pc = pc
        self.pm = pm
        self.glen = glen
        self.group = []
        self.system = system
        self.elite = None

        self.init_group()

    def init_group(self):
        self.group = []
        for _ in range(self.k):
            self.group.append([np.random.randint(0,2) for _ in range(self.glen)]+[0])  #数据结构：基因+适应度
    
    def evaluate_group(self):
        #评估，包含自然选择
        #评估算子，根据system的输入输出得到适应度
        for g in self.group:
            fitness = self.system(g[:-1])
            g[-1] = fitness

        #排序
        self.group = sorted(self.group, key=lambda g:g[-1], reverse=True)
        elite = self.group[0] #精英保护
        if self.elite==None or self.elite[-1]<elite[-1]:
            self.elite = deepcopy(elite)

        #自然选择（锦标赛法）
        new_group = [deepcopy(elite)]
        for _ in range(self.k-1):
            samples = random.sample(self.group, self.cho)
            new_group.append(max(samples, key=lambda g:g[-1]))  #选出其中最优的个体

        #种群更替
        self.group = new_group
        
        return self.elite

    def variation(self):
        #变异算子，包含交叉和突变
        #交叉操作:经过选择操作，此时种群数量应当为k，且排序过
        for i in range(self.k-1):
            for j in range(i+1, self.k):
                x = self.group[i]
                y = self.group[j]
                if random.random() < self.pc:
                    child = [g for g in y]  #复制亲本基因
                    for t in range(self.glen-1):
                        #两者基因按照 50% 概率交换，得到子代
                        if random.random() <0.5:
                            child[t] = x[t]
                    self.group.append(child) #加入子代
            
        #突变操作:全部个体的基因点位按概率pm突变
        for g in self.group:
            for t in range(self.glen-1):
                if random.random()<self.pm:
                    g[t] = 0 if g[t]==1 else 1  #翻转突变

    def update(self):

        #变异
        self.variation()

        #评估和选择
        return self.evaluate_group()

```

### Q-Learning

Q-Learning是一种table方法，利用表格记录State Value和Policy，其利用时序差分方法来求解贝尔曼最优方程：
$$
Q(s_{t},a_{t})\gets Q(s_{t},a_{t})+\alpha[\underbrace{R_{t}+\gamma\operatorname*{max}_{a}Q(s_{t+1},a)-Q(s_{t},a_{t})}_{TD-error}]
$$
逼近值即为：$\max_{\pi} \mathbb{E}[R_{t+1}+\gamma\operatorname*{max}_{a}Q(s_{t+1},a)]$

简化 $\epsilon-greedy$ 软策略：
$$
\pi_{t+1}(a|s_t)=\left \{
\begin{aligned}
&1-\varepsilon, ~~ a=\arg\max_{a}q_{t+1}(s_{t},a) \\
&\varepsilon, ~~ other \\
\end{aligned}
\right.
$$
具体实现：

环境类

- 环境类不记忆任何和强化学习相关的状态，只负责输入输出和奖励
- 输入输出都是环境动作（比如此处定义 {“index”:0, “value”:1} 表示取第一件物品），以及环境状态，例如 [0, 1, 0, 1] 表示当前状态取第二和第四件物品
- step函数描述了转移过程，即以一个状态触发，做出动作后，将返回怎样的回报
  - 这即为遗传算法中的“评估”，即环境给予的

```python
class Env:
    def __init__(self, bag_weights, bag_values, max_w):
        self.bag_weights = bag_weights
        self.bag_values = bag_values
        self.max_w = max_w

    def reset(self):
        return [np.random.randint(0, 2) for _ in range(len(self.bag_values))]  #初始环境状态
    
    def evaluation(self, state):
        #评估函数，根据当前状态评估奖励
        sum_w = 0
        sum_v = 0
        for i, s in enumerate(state):
            if s==1:
                sum_v += self.bag_values[i]
                sum_w += self.bag_weights[i]

        if sum_w > self.max_w:
            return -100
        return sum_v

    def step(self, state, action):
        '''
        动作编码：0 1 2 3 4...
        0 表示 第1个二进制位 = 0
        1 表示 第1个二进制位 = 1
        以此类推

        return next_state, reward
        '''
        #根据动作转移状态
        s_next = [i for i in state]
        s_next[action['index']] = action['value']

        #评估状态
        r = self.evaluation(s_next)
        return s_next, r  #返回下一个状态以及奖励
```



Agent类

- 需要记忆 Q(s, a), 即Action Value，形式上是一个二维数组；Q(s,a) 掌管动 $A$ 的分布
- 由于环境状态不一定是 int， 因此需要环境状态（可列有限）的索引 state_encoder
- 由于输出动作是从 Q(s,a) 中查表的，因此需要对应环境动作的 action_decoder
- 需要有一个状态初始化过程，相当于GA的初始化种群
- 由于时序差分性质，需要记忆状态-动作组 $(s_t, a_t)$
- take_action 输出的是环境动作，用于给环境 env 进行状态转移
- update 函数接收环境的反馈，并更新状态和记忆
- 由于只能由 env 来告诉 agent 在采取当前动作后，将会转移到哪个状态，因此环境 env 和 agent 需要有一个共享变量 state 来交换状态信息

```python
class QLearning:
    """ Q-learning算法 """
    def __init__(self, n_state, n_action, epsilon, alpha, gamma):
        self.Q_table = np.zeros([n_state, n_action])  # 初始化Q(s,a)表格
        self.n_action = n_action  # 动作个数
        self.alpha = alpha  # 学习率
        self.gamma = gamma  # 折扣因子
        self.epsilon = epsilon  # epsilon-贪婪策略中的参数

        self.s = 0 
        self.a = 0

    def init_state(self, init_state):
        #初始化
        state_encode = self.state_encoder(init_state)
        self.s = state_encode
        self.a = 0

    def state_encoder(self, state):
        #将物理状态对应到 tablet 状态的索引
        return sum([2**i*s for i,s in enumerate(state)])

    def action_decoder(self, action):
        #将 tablet 选出的动作索引对应到物理动作
        return {'index':action // 2, 'value':0 if action%2==0 else 1}

    def take_action(self):  #选取下一步的操作（软策略）
        '''
        这里完成动作和状态的编解码，因为实际存于tablet中的只有索引，需要将其对应到具体的动作和状态
        '''
        if np.random.random() < self.epsilon:
            action = np.random.randint(self.n_action)
        else:
            action = np.argmax(self.Q_table[self.s])

        self.a = action  #记忆动作

        return self.action_decoder(action)  #输出环境动作，用于交互

    def best_action(self, state): 
        state_encode = self.state_encoder(state)
        return self.action_decoder( np.argmax(self.Q_table[state_encode]))
    
    def update(self, r, s_next):
        s1 = self.state_encoder(s_next)
        
        td_error = r + self.gamma * self.Q_table[s1].max() - self.Q_table[self.s, self.a]  #计算TD-error
        self.Q_table[self.s, self.a] += self.alpha * td_error #时序差分更新

        #状态记忆
        self.s = s1
```

- 由于只能由 env 来告诉 agent 在采取当前动作后，将会转移到哪个状态，因此环境 env 和 agent 需要有一个共享变量 state 来交换状态信息

迭代信息：

- 共训练 10 轮 (Iteration)

- 每个序列让agent按照软策略自由转移 100 次

```python
from tqdm import *
np.random.seed(0)

epsilon = 0.1
alpha = 0.1
gamma = 0.9

agent = QLearning(16, 8, epsilon, alpha, gamma)
env = Env([1,2,3,4], [2,4,4,5], 5)

num_iter = 10
num_seqs = 50

return_list = []  # 记录每一条序列的回报
for i in range(num_iter):  # 显示10个进度条
    # tqdm的进度条功能
    with tqdm(total=num_seqs, desc='Iteration %d' % i) as pbar:
        for i_episode in range(num_seqs):  # 每个进度条的序列数
            episode_return = 0

            state = env.reset()
            agent.init_state(state)

            sampling_len = 100   #探索步长
            for sp in range(sampling_len):
                action = agent.take_action()  #输出环境动作
                state, reward = env.step(state, action)  #接受环境动作、环境状态，得到奖励和下一个状态
                episode_return += reward  # 这里回报的计算不进行折扣因子衰减
                agent.update(reward, state)  #贝尔曼优化

            return_list.append(episode_return)
            if (i_episode + 1) % 10 == 0:  # 每10条序列打印一下这10条序列的平均回报
                pbar.set_postfix({
                    'episode':
                    '%d' % (num_seqs * i + i_episode + 1),
                    'return':
                    '%.3f' % np.mean(return_list[-10:])
                })
            pbar.update(1)

episodes_list = list(range(len(return_list)))
plt.plot(episodes_list, return_list)
plt.xlabel('Episodes')
plt.ylabel('Returns')
plt.title('Q-learning')
plt.show()
```

  - Q-Learning和GA都需要一个编码解码的过程，后续DQN等算法可抛弃编解码过程，然而，GA仍然需要较为严格的编解码方案，因为GA需要一套在变异算子下闭合的编码空间

- 在线和离线
  - 实操Q-Learning时，发现一个有趣的性质：给定任意 $(s_t, a_t)$，环境都可以给出 $(r_{t+1},s_{t+1})$，而agent的更新也只需要$(s_t, a_t, r_{t+1}, s_{t+1})$ ；那么调整一下顺序：先使一个agent进行足够长的游走，确保访问了足够多的状态，采集序列 $\{(s_t, a_t, r_{t+1}, s_{t+1})\}_{i=1}^N$ 后，再让agent用这个序列数据进行update一步一步update即可
  - 上述称为离线算法，而诸如 Sarsa 一类需要 $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$ 的更新数据，当模型 update后，其根据 $(s_t, a_t, r_{t+1}, s_{t+1})$ 做出的动作 $a_{t+1}$ 的分布将和搜集序列中的 $a_{t+1}$ 分布不一致，因此无法离线更新
  - 判断二者类别的一个重要手段是看计算时序差分的价值目标的数据是否来自当前的策略
