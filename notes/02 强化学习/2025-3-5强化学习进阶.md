# 强化学习进阶（四）

本篇将承接策略梯度法，引入“演员-评论家”范式（Actor-Critic）

当价值和策略全部参数化后，我们将执行策略的模型称为Actor，将评估动作价值的模型称为Critic，由于策略梯度的存在，该算法仍然为在线算法：

$$
\nabla J(\theta) = \mathbb{E}_{\pi_\theta}[\Psi^{\pi_\theta}(s,a) \nabla \ln{\pi_{\theta}(a|s)}]
$$
此处将 $Q^{\pi_\theta}(s,a)$ 换成了 $\Psi^{\pi_\theta}(s,a)$，这个量可以换成任何能够评估动作优劣的量：

|                             公式                             |           含义           |
| :----------------------------------------------------------: | :----------------------: |
|                 $\sum_{n=0}^{T}\gamma^nr_n$                  |        轨迹总回报        |
|               $\sum_{n=t}^{T}\gamma^{n-t} r_n$               |  动作 $a_t$ 之后的回报   |
|          $\sum_{n=t}^{T}\gamma^{n-t} r_n - b(s_t)$           |      基线改进版回报      |
|                  $Q^{\pi_\theta}(s_t, a_t)$                  |       动作价值函数       |
| $A^{\pi_\theta}(s_t, a_t)=\sum_{n=t}^{T}\gamma^{n-t} r_n - V^{\pi_\theta}(s_t)$ | 动作优势函数（**A2C***） |
| $r_t + \gamma V^{\pi_\theta}(s_{t+1}) - V^{\pi_\theta}(s_t)$ | 时序查分残差（优势近似） |

*A2C：用优势函数估计策略梯度时，称为 Advantage Actor Critic（A2C）法



### Actor-Critic范式

将前面所述的价值函数方法和策略梯度方法融合，即得到AC方法：
$$
\text{Value Update:}~~~~ &L(w) = \frac{1}{2}(r_t + \gamma V_w(s_{t+1}) - V_w(s_t))^2 \\
\text{Policy Update:} ~~~&\nabla J(\theta) = \mathbb{E}_{\pi_\theta}[\Psi^{\pi_\theta}(s,a) \nabla \ln{\pi_{\theta}(a|s)}]
$$
这个解决的仍然是离散问题，因为策略学习的依旧是一个多项分布。



##### 确定性策略梯度法（DDPG）

上述策略梯度法出现了 $ \nabla \ln{\pi_{\theta}(a|s)}$ ，这表明函数学习的是一个概率分布，有如下特点：

1. 该模型输出仍然是针对离散动作空间
2. 是在线算法，因为梯度估计中含有 $a_t$，这必须是从 $\pi_\theta(a|s)$ 中采样的，一旦参数改变，则后续经验都将不可使用

为解决连续动作空间，以及能够具有离线性质，我们希望模型根据状态 $s_t$ 直接输出动作:
$$
a_t = \mu_\theta(s_t)~~~~  \mu:\mathcal{S} \rarr \mathcal{A}
$$
**确定性策略梯度定理：**
$$
\nabla J(\theta) = \mathbb{E}[\nabla_\theta \mu(S) \cdot \nabla_a Q(S,a)|_{a=\mu(S)} ]
$$

- 梯度估计中没有出现动作项，因此是一个离线算法

- 由于 $\nabla_a Q(S,a)$ 项的出现，使得价值网络不再是 $Q:\mathcal{S} \rarr \R^{|\mathcal{A}|}$ 的形式，而是：
  $$
  Q := f([s,a]): [\mathcal{S},\mathcal{A}] \rarr \R
  $$
  即根据当前状态，以及 $\mu(s_t)$ 输出的动作直接得到 Action Value

  在梯度下降时，取 $\mathcal{A}$ 部分的梯度，和 $\nabla_\theta \mu$ 相乘得到策略梯度

  

### 问题引入

> 考虑最优控制问题：汽车从 $x=0$ 启动，到 $x_1=100 \text{m}$ 停下，司机可以输入力：
> $$
> F \in [-10,10] ~(N)
> $$
> 负数表示刹车，正数表示加速。只有在加速时候，发动机才做功。
>
> 汽车运动过程中，受空气阻力：
> $$
> f(t)=-kv(t) ~(N)
> $$
> 比例常数 $k=0.5$，汽车质量 $m=5 \text{kg}$，要求汽车停在终点，并使能耗：
> $$
> E = \int_{0}^{x_1} \max \{0, F\} ~\text{d}x
> $$
> 达到最小。求最优控制律 $F(t)$

问题分析：

- 这是一个连续型问题，输出的力是连续型数值
- 该问题具有约束：汽车必须在 $x_1$ 处停下
- 该问题是一个**序贯决策（sequential decision making）任务**，在任何状态 $(x_t, v_t)$，无论采取什么动作，都不可能使得汽车回到这个状态，这是和上篇最速降线问题本质的区别
  - 强化学习得出的解将不再是一个值，而是一个策略

- 遗传算法较为难以解决这个问题，需要将运动过程进行离散化，得到一个高维优化问题，同时需要考虑约束，这对于简单遗传算法是难以解决的



### DDPG

环境实现

- 环境的要求**非常高**，尤其是DDPG这类在连续域进行优化的算法，对于奖励函数非常敏感
  - 错误的奖励将导致agent学习到错误的规律，或者发散
  - 含终端约束（如停止速度为0）的问题不适合DDPG

奖励模型：
$$
\begin{align}
r_{t+1} &= r_{distance} + r_{speed} + r_{time} + r_{goal} \\
&= -|x - 100| - v^2 - 1 + 
\begin{cases}
100 & \text{if } x = 100 \text{ and } v = 0 \\
0 & \text{otherwise}
\end{cases}
\end{align}
$$

- 注意：奖励在状态转移之后计算
- 准确来说，环境不应当储存状态，agent自己储存状态，计算action时，可取其中一部分状态

```py
class CarEnv:
    def __init__(self):
        self.dt = 0.1  # 时间步长
        self.x_end = 100  # 终点位置
        self.m_car = 5  # 汽车质量
        self.k_air = 0.5  # 空气阻力系数
        self.max_T = 50  # 最大时间步数
        self.state = []

    def reset(self):
        self.sumT = 0  # 总时间
        self.sumE = 0  # 总能量消耗
        self.state = [0,0]
        return self.state  # 初始状态 (位移，速度)

    def step(self, action):
        '''
        state = [位移，速度]
        action = 力
        
        return 下一帧状态，当前帧奖励，是否终止
        '''
        x, v = self.state
        f_car = action

        at = f_car/self.m_car
        v1 = v + at * self.dt
        x1 = x + max(v1, 0) * self.dt
        self.sumT += self.dt
        self.state = [x1, v1]

        r = -1*abs(x1 - self.x_end) - v1**2 -1 + (100 if abs(x1-100)<=0.5 and abs(v1)<=0.5 else 0)

        # 刹车条件
        if x >= self.x_end:
            done = True
        else:
            done = False

        res = {
            'T': self.sumT,
            "x": x1,
            "v": v1,
            "F": f_car,
        }

        if self.sumT > self.max_T:
            done = True

        return self.state, r, done, res
```



网络实现

- 一层或者两层隐含层即可
- PolicyNet的输出用tanh或者sigmoid进行动作映射

```py
class PolicyNet(torch.nn.Module):
    def __init__(self, state_dim, hidden_dim, action_dim, action_bound):
        super(PolicyNet, self).__init__()
        
        self.fc1 = torch.nn.Linear(state_dim, hidden_dim)
        self.fc2 = torch.nn.Linear(hidden_dim, hidden_dim)
        self.fc_out = torch.nn.Linear(hidden_dim, 1)

        self.action_bound = action_bound  # action_bound是环境可以接受的动作最大值

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        return self.action_bound * torch.tanh(self.fc_out(x)) 


class QValueNet(torch.nn.Module):
    def __init__(self, state_dim, hidden_dim, action_dim):
        super(QValueNet, self).__init__()
        self.fc1 = torch.nn.Linear(state_dim + action_dim, hidden_dim)
        self.fc2 = torch.nn.Linear(hidden_dim, hidden_dim)
        self.fc_out = torch.nn.Linear(hidden_dim, 1)

    def forward(self, x, a):
        cat = torch.cat([x, a], dim=1) # 拼接状态和动作
        x = F.relu(self.fc1(cat))
        x = F.relu(self.fc2(x))
        return self.fc_out(x)
```



DDPG算法实现

- 此处说明：对于价值网络的梯度下降
  1. 动作目标网络和价值目标网络首先给出目标
  2. .detach() 保证目标网络不参与梯度下降
  3. 价值网络按照均方误差梯度下降
- 动作网络的梯度下降
  1. 动作网络主要用于最大化Q值，因此指标就是critic给出的Q值，由于是最大化，前面乘以-1
- 软同步策略用于更新目标网络参数

```py
class DDPG:

    def __init__(self, state_dim, hidden_dim, action_dim, action_range, actor_lr, critic_lr, tau, gamma, device):
        self.actor = PolicyNet(state_dim, hidden_dim, action_dim, action_range).to(device)
        self.critic = QValueNet(state_dim, hidden_dim, action_dim).to(device)
        self.target_actor =deepcopy(self.actor)
        self.target_critic = deepcopy(self.critic)

        self.actor_optimizer = torch.optim.Adam(self.actor.parameters(), lr=actor_lr)
        self.critic_optimizer = torch.optim.Adam(self.critic.parameters(), lr=critic_lr)
        self.gamma = gamma
        self.tau = tau  # 目标网络软更新参数
        self.action_dim = action_dim
        self.device = device

    def take_action(self, state):
        state = torch.tensor([state], dtype=torch.float).to(self.device)
        action = self.actor(state).item()
        return action

    def soft_update(self, net, target_net):
        for param_target, param in zip(target_net.parameters(), net.parameters()):
            param_target.data.copy_(param_target.data * (1.0 - self.tau) + param.data * self.tau)

    def update(self, seq_info):
        states = torch.tensor(seq_info['states'], dtype=torch.float).to(self.device)
        actions = torch.tensor(seq_info['actions'], dtype=torch.float).view(-1, 1).to(self.device)
        rewards = torch.tensor(seq_info['rewards'], dtype=torch.float).view(-1, 1).to(self.device)
        next_states = torch.tensor(seq_info['next_states'], dtype=torch.float).to(self.device)
        dones = torch.tensor(seq_info['dones'], dtype=torch.float).view(-1, 1).to(self.device)

        #目标网络给出差分目标
        q_values = self.critic(states, actions)
        qvalues_target = rewards + self.gamma * self.target_critic(next_states, self.target_actor(next_states)) * (1 - dones)

        #优化Critic网络
        self.critic_optimizer.zero_grad()
        critic_loss = torch.mean(F.mse_loss(q_values, qvalues_target.detach())) 
        critic_loss.backward()
        self.critic_optimizer.step()

        #优化Actor网络
        self.actor_optimizer.zero_grad()
        actor_loss = -1*torch.mean(self.critic(states, self.actor(states)))  #最大化Q值
        actor_loss.backward()
        self.actor_optimizer.step()

        self.soft_update(self.target_actor, self.actor)
        self.soft_update(self.target_critic, self.critic)
    

    def set_eval(self):
        """
        Sets the model in evaluation mode

        """
        self.actor.eval()
        self.critic.eval()
        self.target_actor.eval()
        self.target_critic.eval()

    def set_train(self):
        """
        Sets the model in training mode

        """
        self.actor.train()
        self.critic.train()
        self.target_actor.train()
        self.target_critic.train()

```



训练过程

- DDPG对于该问题**相当难以训练**
  - DDPG不适合有终端约束的情况
  - 只要有一次到达目标的状态被搜集，agent就有可能再次到达目标
- 问题分析：
  - 在此类时序转移的问题中，奖励函数十分重要
  - 奖励函数分为：**引导项 + 终端项**
  - 引导项负责将agent向目标指引，在训练中，agent可以轻松达到 $x=100 m$ 的地方，终端项则负责检查agent在到达目标时状态是否符合要求
- 出现问题：
  - 由于奖励**积累效应**，终端项很容易被引导项淹没，即使将终端项的力度加大，agent也很难完成任务
  - 噪声是必须添加的，否则agent可能无限循环
  - 经验：
    1. 可视化很重要，最好能看到agent生成并完成任务的过程，以评估任务难以
    2. 噪声是agent是否能初期探索到终点的重要因素
    3. DDPG是旧的算法，确实难以完成此类任务

```py
actor_lr = 3e-6
critic_lr = 3e-5
hidden_dim = 4
gamma = 0.98
tau = 0.001 # 软更新参数
buffer_size = int(1e6)
minimal_size = buffer_size//10
batch_size = 64
device = torch.device("cuda")
replay_buffer = ReplayBuffer(buffer_size)
action_range = 10
iter_nums = 500

env = CarEnv()
state_dim = 2
action_dim = 1
agent = DDPG(state_dim, hidden_dim, action_dim, action_range, actor_lr, critic_lr, tau, gamma, device)

sigma = 10
thres = iter_nums/2
noise_sigmat = lambda t: sigma*np.exp(-2*(t/thres))

# return_list = rl_utils.train_off_policy_agent(env, agent, num_episodes, replay_buffer, minimal_size, batch_size)
return_list = []
with tqdm(total=iter_nums//10) as pbar:
    for t_iter in range(iter_nums):

        episode_return = 0
        state = env.reset()

        done =  0
        while done != 1:
            
            agent.set_eval()
            noise_sigma = noise_sigmat(t_iter)
            action = agent.take_action(state)
            action = np.clip(np.random.normal(action, noise_sigma), -1*action_range, action_range)
            next_state, reward, done, res = env.step(action)
            replay_buffer.add(state, action, reward, next_state, done)
            
            if replay_buffer.size() > minimal_size:
                agent.set_train()
                b_s, b_a, b_r, b_ns, b_d = replay_buffer.sample(batch_size)
                seq_info = {
                    'states': b_s,
                    'actions': b_a,
                    'next_states': b_ns,
                    'rewards': b_r,
                    'dones':b_d,
                }
                agent.update(seq_info)

            state = next_state
            episode_return += reward

        return_list.append(episode_return)

        if t_iter%10==0:
            pbar.set_postfix({
                'episode': f'{t_iter}',
                'noise':f'{noise_sigma:.01f}',
                'best_res': f"{[f'{k}:{v:.02f}' for k,v in res.items()]}",
                'return': f"{np.mean(return_list[-10:]):.02f}",
            })
            pbar.update(1)

```

结果分析：

- 可以看到，agent倾向于直接冲过终点，尽管在终点前，输出的力减小了，然而，并没有停下
- 说明agent并没有学习到**终端约束**，而是更擅长处理**积累效应**
- 当策略网络是深度模型时，沿着策略梯度更新参数，很有可能**由于步长太长**，**策略突然显著变差**，进而影响训练效果
